# Contributing
<!-- KILLROYWASHERE -->

Thanks for helping Veterans. A few rules keep this tool safe and free:

- **No Veteran data, ever.** Don't commit records, outputs, statements or screenshots with
  personal information. Test only with made-up or fully de-identified records.
- **Free forever.** Changes may not add fees, paywalls or referral links. The free-use
  notice must stay on the opening screen and on every page the app makes for the Veteran.
- **Honesty first.** The app writes only true facts in the Veteran's own words. It never
  coaches anyone to exaggerate and never writes a medical opinion for a doctor.
- **No app notices in filed documents.** Statements, packets, letters, logs and witness forms
  go to VA as the Veteran's own.
- **Keep the authorship markers** in every file (see the license: credit is required).
- Before a pull request, run the tests in each `skills/*/scripts/test_*.py` and
  `python3 tools/release_check.py`.
- Plain language: about an 8th-grade reading level; buttons for every choice.

By contributing you agree your work is shared under the same license (CC BY-NC-SA 4.0).
